# Additional assessment scenarios — visible scope

These exercises are short, standardized and job-related. The actual prompt and rating anchors are delivered to all candidates in the same format before each station. Hidden unit tests never invent new feature requirements.

## Scenario: Production incident (10–15 minutes)

A team manager says a project's progress total differs between list and dashboard after multiple engineers update tasks. Explain how you would contain the issue, gather evidence, compare the two query paths, write a failing regression test, roll out safely and alert impacted users. No real infrastructure access is provided.

## Scenario: Product discovery (10–15 minutes)

A construction PM asks: “Notify responsible teams whenever a drawing revision impacts an approved task.” Ask clarifying questions. Define the minimal valuable workflow, authorization, trigger, idempotency, retries, auditing and the smallest measurable MVP. Favor verifiable domain rules over ungrounded AI claims.

## Scenario: Architecture review (15 minutes)

As usage grows from a small internal team to multiple projects and external client reviewers, describe how to evolve a modular monolith, tenant/project authorization, D1/SQLite transaction boundaries, audit log, API versioning, observability, and rollout. Explicitly distinguish required improvements from speculative scale work.

## Scenario: Collaborative code review (10 minutes)

Review a hypothetical PR adding approvals without project scoping. Leave two focused blocking comments, propose tests, and explain the risk without attacking the author. Interviewer records evidence of respectful technical disagreement.
