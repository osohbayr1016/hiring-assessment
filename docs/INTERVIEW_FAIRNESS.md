# Fairness and usage constraints

- Everyone starts from the same pinned commit and receives the same task, tools, timebox and evaluation criteria.
- Use this as an engineering assessment only. The fictional feature should not become unpaid productive work for the employer.
- AI assistants are permitted, but each candidate must describe assisted work and defend changes live.
- Do not share private answers publicly before all candidates finish.
- If the development environment blocks progress, notify the interviewer immediately; setup failures unrelated to engineering skill should be resolved uniformly.
- Favor a safe partial submission with tests and explicit limitations over fragile unverified code with many extra features.
